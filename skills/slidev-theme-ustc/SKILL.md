# slidev-theme-ustc

<!-- TODO: Fill in actual skill instructions -->

A clean academic Slidev theme for USTC-style presentations.

## Setup

```yaml
# In your slides.md frontmatter
theme: @luocfprime/slidev-theme-ustc
```

## Available Layouts

- `cover` — title slide
- `default` — standard content slide
- `content` — body-focused layout
- `split` — two-column layout
- `toc` — table of contents
- `section` — section divider
- `end` — closing slide
- `backup` — backup slides marker
- `blank` — no chrome

## Components

- `Grid`, `Block`, `Abs` — layout helpers
- `Callout`, `FigureBlock`, `TableBlock`, `ResultBox` — content blocks
- `PlotlyGraph`, `QRCode` — interactive/media
- `Takeaway` — key point callout

## Configuration

See `docs/configuration.md` in the theme repository for CSS variables and frontmatter props.
